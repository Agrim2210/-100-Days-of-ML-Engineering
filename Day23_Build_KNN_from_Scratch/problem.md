# Day 23 — K-Nearest Neighbors (KNN)

## Problem
Build a KNN classifier from scratch and compare it with sklearn implementation.

## Dataset
Simple classification dataset (2 features, binary class)

## Goals
- Understand distance-based learning
- Implement KNN manually
- Compare accuracy with sklearn
- Analyze effect of K

## Tasks
1. Implement Euclidean distance
2. Build KNN classifier from scratch
3. Test with different K values
4. Compare with sklearn
